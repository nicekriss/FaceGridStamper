# Face Grid Stamper

캐릭터 시트의 얼굴을 자동 검출하고 교차 격자를 합성하는 Windows 로컬 도구입니다. 원본 파일은 덮어쓰지 않습니다.

어두운 작업 캔버스, 형광 노랑·시안 액션 블록, 굵은 카드 윤곽으로 구성된 **너무바쁜베짱이 모션그래픽 테마**를 적용했습니다.

## 설치

가장 간단한 방법은 [Releases](https://github.com/nicekriss/FaceGridStamper/releases)에서 최신 `windows-x64.exe`를 내려받아 바로 실행하는 것입니다. 설치나 압축 해제가 필요하지 않습니다. 단일 파일이 내부 라이브러리를 임시로 푸는 방식이라 첫 실행은 몇 초 느릴 수 있습니다. Windows SmartScreen이 표시될 수 있으며 현재 빌드는 코드 서명되지 않았습니다.

## 빠른 사용법

1. `FaceGridStamper.exe`를 실행합니다.
2. 이미지를 창에 끌어놓거나 **이미지 열기**를 누릅니다.
3. **얼굴 자동 검출**을 누릅니다.
4. 검출된 얼굴을 클릭해 `격자 → 유지 → 가림` 모드를 전환합니다.
5. 놓친 얼굴은 **영역 직접 추가**를 누르고 얼굴 주위를 드래그합니다.
6. **조절값 기본으로**를 누르면 격자와 검출 조절값이 모두 초기화됩니다.
7. **저장**을 누르면 원본 이미지와 같은 폴더에 `원본이름_얼굴격자.png`로 바로 저장됩니다.
8. 폴더를 직접 선택하려면 **다른 곳에 저장**을 누릅니다. 저장 성공은 소리 나는 팝업 없이 하단 상태표시줄에 나타납니다.

원본 파일은 변경하거나 복사하지 않습니다. 재현에 필요한 격자 설정과 얼굴 영역 정보는 결과 PNG 내부 메타데이터에 함께 기록됩니다.

## 주의

- 얼굴 격자 처리는 실험적인 레퍼런스 컨디셔닝 기법입니다. 원본과 처리본을 같은 조건으로 A/B 비교하세요.
- **가림**은 얼굴 주변의 대표색으로 타원을 채우는 간단한 기능입니다. 복잡한 배경이나 완전한 머리 제거에는 수동 보정이 필요합니다.
- 자동 검출이 틀리면 우클릭으로 영역을 삭제하고 직접 추가하세요.

## 개발 실행

PowerShell에서 `setup.ps1`, `run.ps1` 순서로 실행합니다. 독립 실행 파일을 다시 만들 때는 `build.ps1`을 실행합니다.

얼굴 검출에는 OpenCV YuNet 모델을 사용합니다. 모델 출처: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet
